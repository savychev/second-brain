# 🧠 Second Brain

**Единая точка захвата мыслей.** Пиши или диктуй мысль одной строкой — система сама
определяет, что это (идея, задача, ссылка или заметка), и складывает в нужное место.
Голова свободна, ничего не теряется.

> Статус: **Этап 1 — консольное ядро** ✅ · Java 21 · Maven · без внешних зависимостей во время выполнения, кроме Jackson

---

## Зачем это

Мысли, идеи, задачи и ссылки приходят в течение дня и теряются: часть остаётся в голове,
часть — в разрозненных чатах и заметках. Нет единой точки входа, куда можно быстро «сбросить»
мысль, и системы, которая сама разложит её по местам.

**Second Brain** — это «входная воронка»: захват за секунды, автоматическая классификация,
локальная копия для гарантии «ноль потерь». Хранилище и просмотр — в Notion (этап 2+).

## Что уже умеет (Этап 1)

- ✅ Принимает мысль любой длины и сохраняет с датой
- ✅ Классифицирует на **IDEA / TASK / LINK / NOTE** по правилам (точность ≥ 80% на тестовом наборе)
- ✅ Извлекает `#теги`
- ✅ Хранит всё локально в JSON — после перезапуска ничего не пропадает
- ✅ Интерактивный режим (REPL) и быстрый захват одной командой
- ✅ 17 автотестов, корректная работа с кириллицей на Windows

## Быстрый старт

Нужна только **Java 21+**. Maven ставить не нужно — в проекте есть wrapper (`mvnw`).

```bash
# собрать
./mvnw clean package        # Windows: .\mvnw.cmd clean package

# запустить интерактивный режим
java -jar target/second-brain.jar
```

Пример сессии:

```
› надо купить билеты на самолёт #поездка
  ✓ [TASK] сохранено
    найдено слово-действие: «надо»
    теги: поездка
› идея: тёмная тема для приложения
  ✓ [IDEA] сохранено
    найден маркер идеи: «идея»
› https://spring.io/guides
  ✓ [LINK] сохранено
    в тексте есть ссылка
› :stats
  Всего заметок: 3
    IDEA : 1
    TASK : 1
    LINK : 1
    NOTE : 0
› :quit
```

Команды REPL: `:list [ТИП]`, `:stats`, `:help`, `:quit`.

### Быстрый захват одной командой (Windows)

На Windows передача кириллицы через аргументы командной строки ненадёжна (JVM декодирует
их системной кодовой страницей). Поэтому для быстрого захвата есть PowerShell-обёртка
`sb.ps1`, которая шлёт текст в приложение через stdin в UTF-8:

```powershell
.\sb.ps1 "надо позвонить врачу завтра #здоровье"
```

> Заметки хранятся в `data/notes.json`. Путь можно переопределить переменной
> `SECOND_BRAIN_DATA`. Папка `data/` не коммитится (личные мысли).

## Как работает классификация

Этап 1 — прозрачные правила ([`RuleBasedClassifier`](src/main/java/com/secondbrain/classify/RuleBasedClassifier.java)),
приоритет сверху вниз:

1. есть **слово-действие** (`надо`, `купить`, `позвонить`, `todo`…) → **TASK**
2. есть **маркер идеи** (`идея`, `а что если`, `было бы круто`…) → **IDEA**
3. есть **ссылка** (URL или домен) → **LINK**
4. иначе → **NOTE**

Задача намеренно важнее ссылки: «отправить ссылку …» — это задача, а не закладка.

Точность проверяется тестом на наборе из ~30 реальных мыслей
([`RuleBasedClassifierTest`](src/test/java/com/secondbrain/classify/RuleBasedClassifierTest.java)).
Слабые места правил закроет умная классификация через Anthropic API (этап 4) — интерфейс
[`Classifier`](src/main/java/com/secondbrain/classify/Classifier.java) готов к подмене реализации.

## Архитектура

```
[Вход: консоль → REST API → Telegram-бот]
              ↓
     [Java-бэкенд]
              ↓
 [Классификатор: правила → Anthropic API]
              ↓
[Локальная БД (JSON → SQLite)] → [Notion API]
```

Ключевые швы спроектированы под будущие этапы: за интерфейсами `Classifier` и
`NoteRepository` реализации меняются без переписывания остального кода.

```
src/main/java/com/secondbrain/
├── App.java                     точка входа (REPL / one-shot)
├── model/       Note, NoteType  доменная модель
├── classify/    Classifier, RuleBasedClassifier, Tags
├── storage/     NoteRepository, JsonNoteRepository
├── core/        CaptureService  оркестрация: классифицировать → теги → сохранить
└── cli/         ConsoleApp      консольный интерфейс
```
